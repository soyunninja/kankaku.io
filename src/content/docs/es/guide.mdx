<h2 id="install">Instalar</h2>

```
pi install npm:kankaku
```

También: `pi install git:github.com/soyunninja/kankaku` (añade `@v0.4.6` para fijar versión), o `pi install /ruta/local` sin copiar. Probar sin instalar: `pi -e /ruta/local`.

<h2 id="first-session">Tu primera sesión</h2>

No actives nada — kankaku mide desde el siguiente prompt. Si tienes un hub, al abrir un proyecto nuevo te pregunta el cliente y el proyecto; puedes saltarlo, y si dices que sí a recordarlo, no vuelve a preguntar.

<h2 id="numbers">Tus números</h2>

```
/kankaku            # resumen de hoy
/kankaku tasks      # una línea por tarea
/kankaku sync       # sube lo pendiente al hub
/kankaku export     # csv o json
```

<h2 id="hub">Conectar el hub (opcional)</h2>

```
export KANKAKU_PB_URL="https://tu-hub.example"
export KANKAKU_PB_EMAIL="service@tu-hub.example"
export KANKAKU_PB_PASSWORD="…"
```

Usa una cuenta de servicio, nunca la tuya. Sin esto, kankaku funciona igual — el cliente queda como texto libre.

**Con [Engram](https://gentlemanprogramming.com/#engram).** Si el hub tiene Engram configurado, cada sesión llega con su objetivo y un resumen de lo hecho, junto al tiempo y el coste. Se activa con `KANKAKU_ENGRAM_URL` en el servidor del hub. Sin Engram, el hub se ve exactamente igual.

<h2 id="subagents">Subagentes y gentle-ai</h2>

kankaku no necesita gentle-ai. Lo esencial sale de los eventos de pi: trabajo frente a espera, tokens, coste, modelo, recuperación ante caídas y sincronización con el hub.

Donde sí importa el mecanismo es en los subagentes:

- **gentle-pi** y **pi-subagents** marcan a sus hijos. kankaku los une a su orquestador con certeza, coste incluido.
- El **ejemplo de subagentes de pi** no marca nada. kankaku lo une por ascendencia de procesos, comprobando la identidad del proceso.
- Otro mecanismo: decláralo con `KANKAKU_SUBAGENT_TOOLS` y `KANKAKU_SUBAGENT_CHILD_ENV`. Si no, un hijo detectado queda como incierto: su tiempo se reporta aparte y nunca se cuenta como tarea nueva.

La etiqueta `review` viene preparada para `gentle-ai review`. Si no lo usas, no aparece. Se cambia con `KANKAKU_SEGMENTS`.

<h2 id="notes">Bueno saberlo</h2>

- El prompt nunca sale de tu máquina salvo que lo actives.
- Un subagente en paralelo no duplica el tiempo.
- Un corte no borra nada — queda marcado como interrumpido.
- kankaku estima el coste; nunca factura.
- `/kankaku doctor` diagnostica sin tocar la red.

| Medida | Qué es |
|---|---|
| tiempo de trabajo | lo que trabajó de verdad |
| tiempo de espera | lo que te esperó a ti |
| wall-clock time | el total, de principio a fin |
